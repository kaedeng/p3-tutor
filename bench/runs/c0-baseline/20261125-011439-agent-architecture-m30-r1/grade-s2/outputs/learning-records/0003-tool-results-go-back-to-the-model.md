# A tool's result goes back to the model for its next step

Riley can explain from memory that a tool's result becomes part of the model's next input so the model can decide what to do next, and can count one model call per tool request plus one for the final answer.
This is a base for teaching context: what goes into each call, and why a longer loop costs more.

**Evidence:** quiz 0001, submission s2 (four days after the agent-loop session), items q1, q2 and q5 correct; the count in q4 was right, though its reasoning was not (see record 0004).
