Context, memory and retrieval

From Lesson 1.

Terms

TokenSmall chunk of text; the unit of size and billing
ContextEverything the model can read in one call
Context windowToken limit for a call, reply included
StatelessA call carries nothing into the next one by itself
Short-term memoryHistory of one conversation, kept by software and re-sent
Long-term memoryStored outside the context; loaded in later sessions
RetrievalSearch stored material; add only relevant pieces to context

Before saving to long-term memory, ask

  1. Will it matter in a later session?
  2. Will it still be true then?
  3. Is there already an official source? If so, look it up there.

Cost

  • Total input = the sum of the input of every call.
  • Cost = tokens ÷ 1,000,000 × price per million (input and output priced separately).

Keeping context small

  • Clear old tool results (may be needed again).
  • Trim stale messages (may still matter).
  • Compaction: summarize and continue (details can be lost).
  • Write notes outside the window (must stay correct and findable).

Retrieval

  1. Ahead of time: split into chunks, keep page numbers, prepare the search.
  2. Per question: search, take the top few, add them to the context.
  3. Keyword (BM25): exact codes and terms. Embeddings: similar meaning. Hybrid: both.
  4. Ask the model to cite pages and to say when the answer is not there.
