Context and memory

From lesson 1.

Terms

TokenUnit of text; in English roughly 4 characters, or 100 tokens per 75 words (estimate).
Context windowAll text the model can refer to in a call: system prompt, tool definitions, messages, tool results, reply.
Short-term memoryOne conversation's history, kept by your program.
Long-term memorySaved outside the context, loaded back in later sessions.
CompactionSummarize a long history and continue from the summary. Can lose details.
RetrievalSearch a collection and add only the relevant chunks.
Keyword searchMatches words. Good for exact codes and technical terms.
Embedding searchMatches meaning. Handles different wording; can miss exact matches.

Where does each item live?

Ask in orderHome
1. Needed on every call?System prompt or tool definitions
2. Another system holds the current value?Fetch with a tool
3. Part of a large body of text?Retrieval
4. Only matters in this conversation?Message list; clear or summarize as it grows
5. Matters next visit, no other home?Note saved under the user's ID

Cost of one request

Total input = the input of call 1 + call 2 + … where each call carries the history so far. The window limits the largest call; the bill follows the sum. Price output tokens separately, and check whether cached input is cheaper.
